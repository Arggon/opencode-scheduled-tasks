## Writing a runbook

One file per procedure in this directory. Minimum structure:

1. **When to run it** — symptoms and triggers.
2. **Prerequisites** — access, tooling, inputs.
3. **Steps** — numbered, copy-pasteable commands with expected output.
4. **Verification** — how you know it worked.
5. **Rollback** — how to undo it safely.

Update a runbook in the same PR that changes the procedure it describes.
